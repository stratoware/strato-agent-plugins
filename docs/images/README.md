# Setup screenshots

These screenshots were captured from the running qms17 local Strato stack, using the demo tenant's **Settings → MCP connections** page. They show the actual application UI. The token creation screenshot includes the surrounding Settings page for context.

- `strato-mcp-connections.png`: MCP connections settings before any token is created.
- `strato-create-mcp-token.png`: token creation form with a descriptive name, DHF read/write permissions selected, and Vault attachments unchecked.

The creation dialog was cancelled after capture. No token was created, revealed, copied, or included in these images. Refresh the images when the navigation, permission labels, or token creation flow changes. Capture only a local demo environment and do not include customer data or credentials.
