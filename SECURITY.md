# Security reporting

We support the latest release on the `stable` branch.

Report suspected plugin vulnerabilities using [GitHub's private vulnerability reporting form](https://github.com/stratoware/strato-agent-plugins/security/advisories/new). Include the affected release, client version, impact, and a minimal reproduction. Remove credentials and confidential data before submitting.

Use [public issues](https://github.com/stratoware/strato-agent-plugins/issues) for ordinary bugs and feature requests.
